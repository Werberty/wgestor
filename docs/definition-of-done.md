Uma Issue só é considerada concluída quando TODOS os itens abaixo forem verdadeiros:
•​ ☐ Implementada
•​ ☐ Testada (cobrindo casos de sucesso e de erro)
•​ ☐ Regras de negócio da seção 6 validadas
•​ ☐ Permissões verificadas (quem pode e quem não pode)
•​ ☐ Sem código duplicado relevante
•​ ☐ Code Review realizado pelo outro desenvolvedor
•​ ☐ CI passando (lint + testes)
•​ ☐ Documentação atualizada quando aplicável
•​ ☐ Pull Request aprovado
•​ ☐ Merge realizado em develop
